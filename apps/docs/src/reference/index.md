# API reference

Generated from the package sources on every docs build. Each page lists the
exported functions, classes, interfaces and types with their doc comments.

- [@vttforge/core](/reference/core/): `registerSystem`, `registerModule`, the base factories, `fields()`, `SystemConfig`, `createMigrationRunner`, `VttfError`
- [@vttforge/types](/reference/types/): the Foundry surface the bases stand on
- [@vttforge/cli](/reference/cli/): the commands as functions, for tooling built on top
- [@vttforge/vite-plugin](/reference/vite-plugin/): the plugin and its options
- [@vttforge/testing](/reference/testing/): `withMockFoundry` and the Quench helpers

The guide is the place to start; the reference is for when you know what you
are looking for.
