`promptFields(fields, options)` shows a dialog built from a list of fields (`text`, `textarea`, `number`, `checkbox`, `select`) through Foundry's own input helpers and `DialogV2.input`, and resolves to an object typed from the fields, or `null` when dismissed. `promptFieldGroup(field)` returns one form group for a dialog you configure yourself.
